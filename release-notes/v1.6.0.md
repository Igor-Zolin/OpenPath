## Что нового в OpenPath 1.6.0 для Windows

- **Удобнее управлять исключениями TUN.** Шаблоны, адреса и приложения получили отдельные вкладки. Окно стало шире, длинные подсказки убраны. Адрес можно добавить клавишей Enter, а удалить адрес или приложение — кнопкой «Удалить» прямо в его строке.
- **Виден состав каждого шаблона.** Разверните «Посмотреть правила» у российских сетей, служб Microsoft или LAN. Поиск помогает найти нужный домен или диапазон IP до включения шаблона.
- **Приложения можно добавлять из поиска.** Начните вводить название или имя процесса и выберите приложение из выпадающего списка. Если его нет в результатах, введите имя .exe и нажмите Enter или выберите файл на диске.
- **Проще перезапустить клиент с правами администратора.** При обычном запуске вверху окна появляется уведомление с кнопкой перезапуска. Его можно закрыть до следующего запуска.

Для x64 и ARM64 доступны переносимый EXE и установщик. Для обновления установленной копии запустите файл с окончанием `-Setup.exe` для вашей архитектуры.
